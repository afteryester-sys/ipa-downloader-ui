# Feature Specification: 007-firmware-batch-all-and-selection-animations

**Feature Title**: Пакетные действия со всеми устройствами и плавная анимация переключения моделей  
**Target Version**: 1.8.50  
**Status**: In Progress  

---

## 1. Problem Statement & User Pain Points

1. **Отсутствие пакетных кнопок для всей группы устройств**:
   - Пользователь добавляет несколько моделей в список «Мои устройства» (например, iPhone 17 Pro Max, iPhone 17e и др.).
   - В интерфейсе присутствуют только кнопки для текущего выбранного устройства: «Проверить прошивки» и «Скачать все подписанные».
   - Кнопки запуска проверки и скачивания для **всей пачки устройств** либо отсутствуют на основном экране, либо спрятаны в виде неприметной 10px иконки, из-за чего пользователю приходится вручную переключать каждое устройство и кликать по отдельности.
2. **Резкое переключение обводки и карточек устройств**:
   - При клике по разным карточкам устройств в списке «Мои устройства» синяя рамка выделения (`Brush.Accent`) и фоновая подсветка переключаются мгновенно без какой-либо анимации.
   - Отсутствует тактильный отклик на нажатие (press feedback), анимация перехода и плавное появление выделения.
   - Содержимое таблицы прошивок справа переключается рывком.

---

## 2. User Scenarios & Acceptance Criteria

### Сценарий 1: Пакетный запуск проверки всей пачки устройств
- **Дано**: В списке «Мои устройства» добавлено 2 или более устройства.
- **Когда**: Пользователь нажимает кнопку **«Проверить все ({N})»** (в тулбаре над прошивками или в блоке устройств).
- **Тогда**:
  - Запускается асинхронный опрос актуальных TSS статусов для всех моделей из списка.
  - Кнопка показывает состояние загрузки / анимацию вращения и блокирует повторные нажатия на время выполнения.
  - По завершении выводится информативное сообщение о количестве проверенных устройств.

### Сценарий 2: Пакетное скачивание прошивок для всей пачки устройств
- **Дано**: В списке «Мои устройства» есть устройства с актуальными подписанными Apple TSS прошивками.
- **Когда**: Пользователь нажимает кнопку **«Скачать для всех ({N})»** (в верхнем тулбаре или в панели пакетных действий).
- **Тогда**:
  - Для каждого отслеживаемого устройства определяются актуальные подписанные прошивки.
  - Производится проверка уже скачанных файлов на диске (по размеру) и проверка существующих заданий в очереди.
  - Все недостающие подписанные прошивки для всех устройств добавляются в очередь загрузок.
  - Отображается всплывающее подтверждение: «Добавлено в очередь: {N} прошивок».

### Сценарий 3: Плавная анимация выделения и тактильный отклик
- **Дано**: Пользователь кликает по карточке другого устройства в сайдбаре «Мои устройства».
- **Когда**: Происходит нажатие и смена выделения.
- **Тогда**:
  - Карточка дает микро-тактильный отклик на нажатие (`Scale` сжимается до `0.97` и плавно возвращается до `1.0`).
  - Синяя рамка выделения не прыгает резко, а плавно проявляется (`Opacity 0 -> 1`) и мягко пружинит (`Scale 0.96 -> 1.0` с `CubicEase Out`).
  - Фоновая подсветка плавно набирает прозрачность (`Opacity 0 -> 1` за 0.20с).
  - Снимаемая рамка с предыдущего устройства плавно растворяется (`Opacity 1 -> 0` за 0.16с).
  - Таблица прошивок справа переключается с аккуратным кросс-фейдом (`Opacity 0.4 -> 1.0`, смещение `TranslateY 6 -> 0 px`).

## 3. UI/UX Requirements & Apple Design System Parity

1. **Кнопки в правом тулбаре**:
   - `[ ↻ Проверить ]` (текущее устройство)
   - `[ ↻ Проверить все ({N}) ]` (вся пачка устройств)
   - `[ ⤓ Скачать выбранные / подписанные ]` (для текущего устройства)
   - `[ ⤓ Скачать для всех ({N}) ]` (для всех устройств в «Мои устройства»)
   - Размещение в гибком `WrapPanel` / `DockPanel` для адаптивности при любых размерах окна.
2. **Панель пакетных действий в сайдбаре устройств**:
   - В нижней части карточки «Мои устройства» блок быстрых действий со всей пачкой:
     - Кнопка «Проверить все» с иконкой `&#xE72C;`
     - Кнопка «Скачать для всех» с иконкой `&#xE896;`
3. **Анимации**:
   - Плавность перехода: `CubicEase` (EasingMode="EaseOut").
   - Длительность появления: `0:0:0.20`, затухания: `0:0:0.16`.
   - Тактильный клик: `0:0:0.07` на сжатие, `0:0:0.16` на возврат.
