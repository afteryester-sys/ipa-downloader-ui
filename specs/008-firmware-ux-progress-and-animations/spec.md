# Feature Specification: 008-firmware-ux-progress-and-animations

**Feature Title**: Улучшения UX прошивок: общий прогресс, индивидуальный прогресс устройств, журнал событий, финализация загрузок и анимация операций  
**Target Version**: 1.8.53  
**Status**: In Progress  

---

## 1. Problem Statement & User Pain Points

1. **Не отображается путь к выбранной папке прошивок**:
   - При открытии настроек прошивок (диалог «Настройки прошивок (IPSW)») и выборе папки через диалог «Обзор...» поле ввода остается пустым либо обрезает текст.
   - Выбранная папка не сохраняется надежно в персистентных настройках пользователя.
2. **Отсутствие общего прогресса очереди и прогресса на карточках устройств**:
   - В нижней панели очереди загрузок есть текстовая строка ("2 активных 58,7 MB/s 0,81 / 23,69 GB"), но нет общего графического прогресс-бара для всей очереди.
   - В левой панели «Мои устройства» карточки устройств не отображают статус и ход загрузки прошивки для конкретной модели.
3. **Зависание на 100% при финализации загрузки**:
   - При скачивании больших файлов (12+ GB) после загрузки последнего байта процесс выглядит «зависшим на 1 сек», пока в фоне идут сборка сегментов (`destination + .assembling`) и расчет SHA-1 хэша. Нет понятного статуса текущей операции («Сборка файла...», «Проверка хэша...»).
4. **Некорректное масштабирование и обрезка кнопок**:
   - В сайдбаре «Пакетные действия» кнопка «Скачать для всех» обрезает текст («Скачать для все:») из-за недостаточной ширины и фиксированного горизонтального расположения.
   - В панели управления над таблицей прошивок при узком окне кнопки наползают друг на друга.
5. **Отсутствие истории/лога событий и отметки времени актуальности**:
   - Нет локального журнала действий раздела прошивок (какие устройства добавлены/удалены, когда выполнялась проверка подписей, какие прошивки скачаны).
   - Нет явной отметки времени, подтверждающей актуальность данных («Проверено: 15.10.2026 02:40 • Подписи Apple TSS актуальны»).
6. **Отсутствие анимации раскрытия меню текущих операций**:
   - При клике на фиолетовый кружок с количеством активных операций окно «Текущие операции» появляется мгновенно без анимации раскрытия из центра кнопки.

## 2. User Scenarios & Acceptance Criteria

### Сценарий 1: Надежный выбор и отображение папки прошивок
- **Дано**: Пользователь открывает «Настройки прошивок (IPSW)» и нажимает «Обзор...».
- **Когда**: Пользователь выбирает папку на диске и подтверждает выбор.
- **Тогда**:
  - Путь отображается в поле ввода полностью, без обрезания по высоте.
  - Путь немедленно сохраняется в конфигурацию (`FirmwareFolder`).
  - При повторном открытии окна путь сохраняется и отображается.

### Сценарий 2: Общий прогресс-бар и индикаторы устройств
- **Дано**: В очереди загружаются одна или несколько прошивок.
- **Когда**: Идут сетевые операции.
- **Тогда**:
  - В шапке панели «Очередь загрузок» отображается аккуратный общий прогресс-бар (`OverallProgress`, 0–100%).
  - На карточке соответствующего устройства в списке «Мои устройства» отображается компактный индикатор прогресса (тонкий прогресс-бар + процент/скорость).

### Сценарий 3: Понятная финализация загрузки
- **Дано**: Загрузка 100% байт файла завершена.
- **Когда**: Файл собирается и проверяется.
- **Тогда**:
  - Статус задания четко отображает: «Сборка файла...» / «Проверка SHA-1...».
  - По завершении статус моментально переходит в «Готово» с кнопкой открытия в проводнике.

### Сценарий 4: Адаптивные кнопки без обрезки текста
- **Дано**: Список «Мои устройства» и тулбар над таблицей.
- **Когда**: Окно имеет стандартный или компактный размер.
- **Тогда**:
  - В блоке «Пакетные действия» кнопки «Проверить все» и «Скачать для всех» размещены вертикальным стеком или адаптивной сеткой с полным текстом и иконками без обрезания.
  - В верхнем тулбаре кнопки адаптируются без наплывов.

### Сценарий 5: Журнал событий и статус актуальности
- **Дано**: Пользователь находится на вкладке «Прошивки».
- **Когда**: Пользователь нажимает на значок журнала/истории.
- **Тогда**:
  - Открывается панель/поповер истории с записями о последних операциях с датой и временем.
  - В интерфейсе видна отметка последней успешной проверки TSS с точным временем.

### Сценарий 6: Плавное раскрытие плашки операций из кружка
- **Дано**: В правом верхнем углу активен кружок счетчика операций.
- **Когда**: Пользователь кликает по нему.
- **Тогда**:
  - Всплывающее окно плавно разворачивается (`ScaleTransform 0.2 -> 1.0`, `Opacity 0 -> 1`) с точкой привязки в верхнем правом углу (из центра кружка) с мягкой физикой `CubicEase`.
  - При закрытии плавно сворачивается обратно.
